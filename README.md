# Bierpong Turnier – App

Turnierbaum für Bierpong (Double Elimination, 2–32 Teams, Tische und Zeiten einstellbar).
Läuft komplett im Browser, auch offline. Der Spielstand wird auf dem Gerät gespeichert.

## Als App aufs iPad / Handy

- **iPad/iPhone:** Link in Safari öffnen → Teilen-Symbol → **Zum Home-Bildschirm**.
- **Android:** Link in Chrome öffnen → Menü (⋮) → **App installieren**.

Danach startet die App im Vollbild ohne Browserleiste und funktioniert auch ohne Internet.

## Wichtig

- Der Stand liegt nur auf dem Gerät, auf dem eingetragen wird. Unter „Teams & Zeiten“ → **Sicherung**
  kannst du ihn als Datei speichern und auf einem anderen Gerät wieder laden.
- Neues Turnier: „Teams & Zeiten“ → **Alles zurücksetzen**.
- Änderst du später Dateien, in `sw.js` die Zeile `VERSION = 'bierpong-v1'` hochzählen (v2, v3 …),
  damit die installierten Apps die neue Version laden.
